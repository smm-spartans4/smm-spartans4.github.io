Publish to parents

Your plays, roster and schedule save in this browser only. Parents see the last published version until you do this:

  1. Export publish file — you get team-data.js.
  2. Replace data/team-data.js in the project folder with it.
  3. Push. Everyone now sees your changes.

Export a backup regularly too. Clearing your browser data wipes the working copy, and an exported file is the only way back — or the way to carry your work to another computer.

Use it at practice with no signal

Install the site and it opens like an app, with every play and this week’s schedule available offline.

iPad or iPhone: open smm-spartans4.github.io in Safari, tap the Share button, then Add to Home Screen. Chrome on iOS will not offer this — it has to be Safari.

Android or desktop Chrome: look for Install in the address bar, or Menu → Install app.
