How publishing works

Everything you build — roster, plays, schedule — saves instantly, but it saves in this browser only. Parents opening the site on their phones see the last published version, not your working copy. Publishing is three steps:

  1. Export publish file below. You get team-data.js.
  2. Replace data/team-data.js in the project folder with it.
  3. Push. Everyone now sees your changes.

Export a backup regularly. Clearing your browser data wipes the working copy, and an exported file is the only way to get it back — or to carry your work to another computer.

Use it at practice with no signal

Install the site and it opens like an app, with every play and this week's schedule available offline — scrub, flip and tap included.

iPad or iPhone: open smm-spartans4.github.io in Safari, tap the Share button, then Add to Home Screen. Chrome on iOS will not offer this — it has to be Safari.

Android or desktop Chrome: look for Install in the address bar, or Menu → Install app.

Load it once on wi-fi before you head to the field. It stays current on its own whenever you open it with a connection.
